S32K344 Evaluation Board

Overview

  • The S32K3X4EVB-T172 is an evaluation board by NXP Semiconductors for the S32K344 general purpose automotive microcontroller (Arm Cortex-M7 with FPU, 4 MB program flash, 512 KB SRAM including the tightly coupled memories).

  • Eclipse OpenBSW provides a reference application for this platform which is built with the s32k344-freertos preset. It offers an interactive console on the OpenSDA VCOM port and CAN/UDS communication. The platform code lives in platforms/s32k3xx (SoC level) and executables/referenceApp/platforms/s32k344evb (board level).

Scope

The platform provides a Cortex-M7 image with no regression to the existing platforms:

  • startup code with vector table and ECC initialization of SRAM and DTCM,

  • a boot header (IVT) for the Boot Assist Firmware, so the image starts from a power cycle once flashed,

  • a linker script placing the image in program flash, the main stack in DTCM and data, BSS and heap in the system SRAM,

  • the clock tree configured to a 160 MHz PLL core clock,

  • the FreeRTOS Cortex-M7 port driven by the SysTick timer,

  • the interrupt manager and the system timer based on the DWT cycle counter,

  • the console on LPUART6 (OpenSDA VCOM port),

  • FlexCAN0 at 500 kbit/s with the docan transport and UDS stack,

  • lifecycle management with the safety supervisor.

Not yet available: IO, the watchdog, the MPU and the persistent storage. The corresponding PLATFORM_SUPPORT_* options are therefore switched off in executables/referenceApp/platforms/s32k344evb/Options.cmake and get enabled as the drivers become available. Open items are marked with TODO comments in the sources.

Build environment

For instructions on building see Set up your environment. The platform uses the same ARM toolchain as the S32K148EVB; the preset selects the Cortex-M7 core and the fpv5-d16 FPU via the OPENBSW_ARM_CPU and OPENBSW_ARM_FPU cache variables:

cmake --preset s32k344-freertos
cmake --build --preset s32k344-freertos

The ELF file is written to build/s32k344-freertos/executables/referenceApp/application/RelWithDebInfo/app.referenceApp.elf.

Flashing and debugging use the PE Micro GDB server together with test/pyTest/flash.gdb and test/pyTest/reset.gdb; SEGGER J-Link and the NXP S32 Debug Probe work as alternatives:

pegdbserver_console -device=NXP_S32K3xx_S32K344 -startserver -serverport=7224

Notes

  • The on-board CAN transceiver of board revision B2 is a TJA1443 CAN FD device. Its EN/STB pins are driven to normal mode by the BSP; no further configuration is required.

  • The C40 flash read wait states are left at the conservative reset default.
